# NVIDIA NIM Proxy

Le proxy NIM expose les modèles NVIDIA via l'URL 127.0.0.1:20200 et assure la traduction entre les appels Hermes et les endpoints NVIDIA. Il est actuellement actif (PID 3672). Voir [[hermes-agent]] et [[omniroute]] pour le contexte.
