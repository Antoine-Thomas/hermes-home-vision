# Gmail OAuth2 Token Refresh

Google OAuth2 tokens in testing mode expire after ~7 days. When this happens, the Gmail API returns:

```
google.auth.exceptions.RefreshError: ('invalid_grant: Token has been expired or revoked.',
{'error': 'invalid_grant', 'error_description': 'Token has been expired or revoked.'})
```

## Refresh Procedure

### Step 1: Generate the auth URL

```bash
SETUP="$HOME/AppData/Local/hermes/skills/productivity/google-workspace/scripts/setup.py"
python "$SETUP" --auth-url
```

This outputs a long URL like:
```
https://accounts.google.com/o/oauth2/auth?response_type=code&client_id=...&redirect_uri=http%3A%2F%2Flocalhost%3A1&scope=...
```

### Step 2: User authorizes in browser

- Open the URL in a browser
- Sign in with the target Gmail account (e.g. `searching.murphy@gmail.com`)
- Google shows a consent screen — accept all scopes
- Browser redirects to `http://localhost:1/?code=...&state=...` — this will show an error page (no server on localhost:1), which is expected
- Copy the **full redirect URL** from the address bar

### Step 3: Complete auth with the code

```bash
python "$SETUP" --finish "http://localhost:1/?code=4/0AanRRrvPht9jYx..."
```

This exchanges the authorization code for a new `google_token.json` in `HERMES_HOME`.

### Step 4: Verify

```bash
GAPI="$HOME/AppData/Local/hermes/skills/productivity/google-workspace/scripts/google_api.py"
python "$GAPI" gmail send --to "you@gmail.com" --subject "Test" --body "Token refreshed"
```

## Pitfalls

- **Do NOT use `--services` flag** — it's not supported in this setup.py version. Just `--auth-url` and `--finish`.
- **Token files**: `google_client_secret.json` (downloaded from Google Cloud Console, permanent) and `google_token.json` (generated by setup.py, expires ~7 days). Both live in `HERMES_HOME` (`~/AppData/Local/hermes/`).
- **Testing vs Production**: In Google Cloud Console, if the app is in "Testing" mode, tokens expire after 7 days. Publish the app to extend token lifetime to indefinite (with refresh).
- **Multiple client_secret files**: If there are several `client_secret_*.json` files in Downloads, `setup.py` copies the first one it finds to `google_client_secret.json`. Ensure the right one is used.
